# 📊 ConsulX

**ConsulX** é uma aplicação web interativa desenvolvida com **Python e Streamlit** para consulta, análise e visualização de dados de forma simples e intuitiva.

🔗 Acesse o aplicativo:  
https://consulx.streamlit.app

---

## 🚀 Sobre o Projeto

O ConsulX foi criado com o objetivo de demonstrar habilidades em **análise de dados, desenvolvimento de aplicações de dados e visualização de informações**. A aplicação permite que usuários explorem dados através de uma interface web interativa, facilitando a obtenção de insights sem a necessidade de trabalhar diretamente com código.

Esse tipo de aplicação é muito utilizado nas áreas de **Data Analytics, Business Intelligence e Ciência de Dados**, pois permite transformar análises em ferramentas acessíveis para diferentes usuários.

---

## ⚙️ Funcionalidades

- Consulta de dados de forma interativa  
- Visualização de dados através de tabelas e gráficos  
- Exploração de informações para análise de dados  
- Interface web simples e intuitiva  
- Navegação fácil para obtenção de insights

---

## 🛠️ Tecnologias Utilizadas

- **Python** – linguagem principal do projeto  
- **Streamlit** – framework para criação de aplicações web de dados  
- **Pandas** – manipulação e análise de dados  
- **Git e GitHub** – versionamento e hospedagem do código  
- **Streamlit Cloud** – deploy da aplicação

## ▶️ Como Executar o Projeto

1. Clone o repositório:

git clone https://github.com/seu-usuario/ConsulX.git

2. Acesse a pasta do projeto:

cd ConsulX

3. Instale as dependências:

pip install -r requirements.txt

4. Execute a aplicação:

streamlit run app.py

Após executar o comando, a aplicação abrirá automaticamente no navegador.
